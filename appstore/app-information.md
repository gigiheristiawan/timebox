## Age Rating

Answer **None / No** to every question in the questionnaire. The result is **4+**.

The two that are easy to get wrong:

- **Unrestricted Web Access — No.** TimeBox draws its interface with a web view,
  but that view loads only local content compiled into the app. It cannot browse
  the web. Answering Yes here would force a 17+ rating.
- **In-app purchases / gambling / contests — No.** There are none.
