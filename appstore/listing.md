## Description  (max 4000)

TimeBox is a menu bar timer built on one idea: the timer controls how long you work on a task, not whether the task is done.

Most timers either nag you or quietly move on. TimeBox does neither. When a block expires it stops and asks what actually happened — and it will not continue until you answer.

THE CHECKPOINT

When time is up, a checkpoint appears with five ways forward: complete the task and start the next one, complete it and take a break, keep it pending and move on, keep it pending and take a break, or extend the block and keep working.

There is no dismiss button, no close, no snooze and no timeout. Escape does nothing. The decision is the point.

Finishing a block never marks a task done. Only you do that.

ROTATION, NOT REPETITION

This is not a Pomodoro app. There are no fixed cycles and no automatic breaks. Give each task a block length that suits it, and TimeBox rotates through the queue.

Switch away mid-block and the task you set down keeps its remaining time. Come back later and you resume the remainder, not a fresh block — so no single task can quietly consume the whole day.

YOUR DAY, VISIBLE

Set the working time you actually have. TimeBox shows what is allocated and what is left, and lets you overcommit visibly rather than by accident. Today's totals show time worked, time spent on breaks, and where it went.

IN THE MENU BAR

The countdown sits in the menu bar. One click opens a popover to start, switch, pause or finish a block without leaving what you are doing, and a global shortcut opens it from anywhere. No Dock icon, no window in the way.

QUITTING DOES NOT STOP THE CLOCK

Deadlines are absolute timestamps, not counters. Quit the app, shut the lid, let the Mac sleep — a block that expired while you were away returns as a checkpoint, not as a reset timer.

PRIVATE BY CONSTRUCTION

No accounts, no analytics, no crash reporting, no network code at all. Everything lives in a local database on your Mac. The source is public.

REQUIREMENTS

macOS 13 or later. Universal — Apple silicon and Intel.
