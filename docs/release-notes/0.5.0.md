TimeBox is a macOS menu bar utility for task rotation timeboxing:

> The timer controls **how long you work on a task**, not whether the task is completed.

0.5.0 is about seeing the timer without going to look for it. There is a new floating overlay that sits over your other windows, and the current block is now tinted wherever it appears, so what the app is doing is answered by colour before anything is read.

## The timer overlay

A small card that floats above whatever you are working in, on your main display. It shows the countdown and the task you are on, the break when you are on one, and — when nothing is running at all — today's idle total, so the reminder does not disappear at exactly the moment it is worth having.

It is **off until you switch it on**: Settings → *Timer overlay*. There you choose whether the task title is shown (it is the half that leaks on a shared screen or a call), which of five positions it sits in, and how solid it looks.

Three things about it are deliberate:

**It cannot be clicked.** The overlay ignores the mouse entirely, so it never takes focus, never swallows a click meant for the editor underneath, and has no button, no drag handle and no close box. It is furniture, not a fourth window to manage. That is also why the position is a setting rather than a drag.

**It gets out of the way of the checkpoint.** When a block expires — or when Pomodoro mode offers a break — the overlay hides itself. The checkpoint fills the same display and has no exit; a card repeating *time's up* on top of it would be noise at the one moment the screen has to carry a single thing.

**Opacity is the whole card, text included.** The slider fades the window itself, which is the only way to do it without the private API that would rule out the App Store. At 0% it is invisible but still there — if the card seems to have vanished, check the slider before the toggle.

It follows you across Spaces, and it uses your theme like every other surface. A native full-screen app can still cover it; that is macOS's call, not ours.

## The current block is tinted

The popover and the main window now paint the current task's panel in a colour that says what state it is in: green while a work block runs, grey while it is paused, blue during a break. Previously that was legible only by reading — the title, the colour of the digits, which buttons happened to be there.

At a checkpoint the panel deliberately stays plain: the banner inside it already carries the alert colour, and tinting behind it would erase the one thing that has to be seen.

*Take a break* now has a warm band of its own at the foot of the popover, separating the one control that is neither the current block nor a setting from the two rows below it.

## Everything else is unchanged

Nothing about how time is recorded changed, and no rule about the timer changed. Switching a task still parks its block and resumes the remainder rather than re-granting the allocation. Block completion is still not task completion. The checkpoint still has no dismiss, no close, no timeout and no `Esc`. Idle is still inferred from the absence of work inside your working window, never observed.

Daily tasks, Pomodoro mode and the weekly Report tab are as they were in 0.4.0.

## Privacy

No account, no network calls, no telemetry. Everything is a local SQLite database under `~/Library/Application Support/xyz.gigiheristiawan.timebox/`. The overlay adds no entitlement and no new source of data — it reads the same state every other window reads.

## Upgrading

There is one migration, and it only adds the four settings the overlay needs. It runs on first launch and needs nothing from you. Your tasks, blocks and recorded time are untouched.

The overlay arrives **switched off**. A window that appeared over everything on upgrade would be a surprise, and this one cannot be clicked away.

If you are coming from 0.3.2 or earlier, read the [0.4.0 notes](0.4.0.md) as well — it carries two migrations, and it is where daily tasks, Pomodoro mode and the report arrived.

If you are coming from 0.2.0 or earlier, read the [0.3.0 notes](0.3.0.md) too — in particular the one manual step there: every task added before 0.3.0 is stored as **Medium** priority regardless of what was picked, and can only be corrected with the editor.

## Install

Requires **macOS 13 or later**. Universal binary — Apple Silicon and Intel.

Open the DMG and drag TimeBox to Applications. The build is signed with a Developer ID certificate and notarized by Apple, so it opens without a Gatekeeper warning.

## Known limitations

- macOS only.
- **The overlay lives on the main display only**, in one of five fixed positions, and cannot be dragged. A full-screen app can cover it.
- **The checkpoint always opens on the main display**, which is not configurable. If you want it on the other screen, change which display is the main one in System Settings → Displays.
- **Sleep is not yet detected.** Closing the lid mid-block is still recorded as work, capped at the block's allocation — and counts toward the Pomodoro clock as well. Quitting is handled; sleeping is not.
- Pomodoro's twenty-five minutes is not configurable, the break offered is one length, and *Skip & continue* means the break is never truly forced.
- Daily is the only recurrence, and there are no streaks.
- The report has no export, no charts, and no range other than a week.
- Worked time recorded before 0.3.2 keeps its old per-block attribution: a block from an earlier version that crossed midnight still reports all of it on the day it started.
- A task's block duration can only be increased, never reduced. If you want a shorter block, remove the task and add it again.
- No import, export, or sync — the database is local and yours to back up.
