TimeBox is a macOS menu bar utility for task rotation timeboxing, built on one idea:

> The timer controls **how long you work on a task**, not whether the task is completed.

This is the first public release.

## The checkpoint

When a block expires, TimeBox opens a screen-filling window with **no dismiss, no close, no timeout, and no `Esc`**, and asks what to do with the task. Finishing the block and finishing the task are separate decisions, and only you make the second one.

|                  | then start next               | then take a break            |
| ---------------- | ----------------------------- | ---------------------------- |
| **Complete**     | `✓ Complete & Start Next` `1` | `✓ Complete & Break 10m` `2` |
| **Keep pending** | `→ Keep Pending & Start Next` `3` `⏎` | `→ Keep Pending & Break 10m` `4` |

Plus `+ Extend Time` `5` — extending has no break pairing, because extending means staying on this task now.

The checkpoint also shows what you would otherwise gloss over: how long ago the block actually ended if you were away, and how much you have already extended this task today.

Nothing in Settings can switch it off. This is not a Pomodoro app — no fixed cycles, no automatic breaks, no streaks.

## What's in it

- **Menu bar first.** No Dock icon, no app-switcher entry. The mark shows `◉ 24:17` while working, `◔ BREAK 04:12` on a break, `⚠ TIME'S UP` at a checkpoint.
- **Popover** — the whole day is workable from here: current task, countdown, next up, pause/skip, and the queue. `Cmd+Shift+T` from any app.
- **Main window** — rotation strip, drag-to-reorder queue, daily capacity, and a Today summary: worked, on break, away, switched early, top tasks.
- **Settings** — theme, default durations, daily capacity, launch at login, sound and notification toggles.
- **Keyboard throughout** — `Space` pause/resume, `N` new task, `S` skip, `D` complete, `↑`/`↓`/`⏎` through the queue, `Cmd+K` quick add.

## The rules it actually enforces

These live in a pure Rust core with tests named after them, so a failure names its requirement.

- **Block completion ≠ task completion.** A task becomes `Done` only through an explicit complete.
- **Switching parks a block; it never re-grants one.** Set a task down at 29:00 of a 30:00 block, come back later, and you resume the remaining 1:00. Otherwise switching away and back would hand out unlimited time without ever reaching a checkpoint.
- **`end_at` is absolute.** Quitting does not stop the clock; only an explicit pause holds a remainder.
- **Away time is banked, not derived** — counted as neither work nor rest, and never back-credited to a task.
- **Breaks carry no task**, never count as worked, and do not consume daily capacity.

## Recovery

Quit mid-block, crash, or close the lid for three days. On launch the app evaluates expiry **before anything renders**, so a block whose time has passed appears as a checkpoint — never as a still-running timer, never silently reset. Recorded work is capped at the block's allocation, so a block reopened days later cannot report days of work.

## Privacy

No account, no network calls, no telemetry. Everything is a local SQLite database under `~/Library/Application Support/xyz.gigiheristiawan.timebox/`. The web view has no path to it — there is deliberately no SQL plugin.

## Install

Requires **macOS 13 or later**. Universal binary — Apple Silicon and Intel.

Open the DMG and drag TimeBox to Applications. The build is signed with a Developer ID certificate and notarized by Apple, so it opens without a Gatekeeper warning.

On first launch, look for the mark in your **menu bar** — there is no Dock icon by design.

## Known limitations

- macOS only.
- No task history browser yet; the Today summary covers the current day.
- No import, export, or sync — the database is local and yours to back up.
