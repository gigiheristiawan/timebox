TimeBox is a macOS menu bar utility for task rotation timeboxing:

> The timer controls **how long you work on a task**, not whether the task is completed.

0.5.2 is a small release about the popover and the overlay: daily tasks are easier to tell apart there, ticked-off dailies stop crowding out work still to do, and task titles have more room.

## Dailies done today move to the bottom of the popover

The popover previews the first five tasks in the queue. Dailies near the head of the queue, once ticked off for the day, used to fill those rows and push the tasks still waiting out of sight.

The popover now lists today's done dailies after everything still open, each group in its usual order. **This is only how the popover displays the queue — nothing is reordered.** The main window still shows the queue exactly as you arranged it, and tomorrow each daily is back where you put it. Moving the daily for real would have left it at the bottom the next day, and a task added after the tick would have landed beneath it and been cut off anyway.

## The daily badge is shown everywhere

The `daily` chip used to appear only in the main window's queue, so from the popover a daily looked like any other task. It now appears on dailies in the popover's list, and on the timer overlay while a daily is running. On the overlay it sits on the title line rather than adding a row, and it hides along with the title if you have switched the title off.

## A wider popover

The popover is 380px wide, up from 300px, so task titles truncate much less. It still opens centred under the menu bar icon.

## Everything else is unchanged

No migration, no schema change, no new setting, and no change to how time is recorded or how the timer behaves.

## Privacy

No account, no network calls, no telemetry. Everything is a local SQLite database under `~/Library/Application Support/xyz.gigiheristiawan.timebox/`. This release adds no entitlement and no new source of data.

## Upgrading

Your existing database opens unchanged. There is no migration in this release and nothing to do by hand.

If you are coming from 0.4.1 or earlier, read the [0.5.0 notes](0.5.0.md) as well — it carries migration 007 and it is where the overlay and the tinted current block arrived — and the [0.5.1 notes](0.5.1.md), which fixed the overlay not updating.

If you are coming from 0.3.2 or earlier, read the [0.4.0 notes](0.4.0.md) too — two migrations, and where daily tasks, Pomodoro mode and the report arrived.

If you are coming from 0.2.0 or earlier, read the [0.3.0 notes](0.3.0.md) as well — in particular the one manual step there: every task added before 0.3.0 is stored as **Medium** priority regardless of what was picked, and can only be corrected with the editor.

## Install

Requires **macOS 13 or later**. Universal binary — Apple Silicon and Intel.

Open the DMG and drag TimeBox to Applications. The build is signed with a Developer ID certificate and notarized by Apple, so it opens without a Gatekeeper warning.

## Known limitations

- macOS only.
- **The overlay's opacity fades the whole card, text included** — at 0% it is invisible but still there. If it seems to have vanished, check the slider before the toggle.
- A native full-screen app can cover the overlay. That is macOS's call, not ours.
- **The checkpoint always opens on the main display**, which is not configurable. If you want it on the other screen, change which display is the main one in System Settings → Displays.
- **Sleep is not yet detected.** Closing the lid mid-block is still recorded as work, capped at the block's allocation — and counts toward the Pomodoro clock as well. Quitting is handled; sleeping is not.
- Pomodoro's twenty-five minutes is not configurable, the break offered is one length, and *Skip & continue* means the break is never truly forced.
- Daily is the only recurrence, and there are no streaks.
- The report has no export, no charts, and no range other than a week.
- Worked time recorded before 0.3.2 keeps its old per-block attribution: a block from an earlier version that crossed midnight still reports all of it on the day it started.
- A task's block duration can only be increased, never reduced. If you want a shorter block, remove the task and add it again.
- No import, export, or sync — the database is local and yours to back up.
