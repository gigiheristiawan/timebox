TimeBox is a macOS menu bar utility for task rotation timeboxing:

> The timer controls **how long you work on a task**, not whether the task is completed.

0.3.1 is a small fix release. Finishing a task from the menu bar popover was not possible — you had to open the main window to do it.

## Complete a task from the popover

The popover's current task now offers **Complete** beside Pause and Skip. It does exactly what the main window's button does: ends the current block as completed, marks the task done, and starts the next task in the queue.

The intent of the popover is that a normal day is possible from it alone — start, pause, skip, switch, take a break. Completing a task was the one everyday operation missing from that list.

It is not offered where it would be wrong. At an expired-block checkpoint the popover still says only that a decision is owed: the checkpoint has no side doors, and `Complete` there would have been one. During a break the controls stay `+5 min` and `End break`, and with nothing running there is nothing to complete.

## Everything else is unchanged

No migration, no schema change, no new setting, and no change to how time is recorded. Everything in 0.3.0 — the inline task editor, the priority fix, drag-to-reorder — is as it was.

The checkpoint still has no dismiss, no close, no timeout and no `Esc`. Switching a task still parks its block and resumes the remainder rather than re-granting the allocation. Block completion is still not task completion. Idle is still inferred from the absence of work inside your working window, never observed.

## Privacy

No account, no network calls, no telemetry. Everything is a local SQLite database under `~/Library/Application Support/xyz.gigiheristiawan.timebox/`. This release adds no entitlement and no new source of data.

## Upgrading

Your existing database opens unchanged. There is no migration in this release and nothing to do by hand.

If you are coming from 0.2.0 or earlier, read the [0.3.0 notes](0.3.0.md) as well — in particular the one manual step there: every task added before 0.3.0 is stored as **Medium** priority regardless of what was picked, and can only be corrected with the editor.

## Install

Requires **macOS 13 or later**. Universal binary — Apple Silicon and Intel.

Open the DMG and drag TimeBox to Applications. The build is signed with a Developer ID certificate and notarized by Apple, so it opens without a Gatekeeper warning.

## Known limitations

- macOS only.
- **Sleep is not yet detected.** Closing the lid mid-block is still recorded as work, capped at the block's allocation. Quitting is handled; sleeping is not.
- A task's block duration can only be increased, never reduced. If you want a shorter block, remove the task and add it again.
- Idle is reported as one total. The causes behind it — paused, waiting at an unanswered checkpoint, no block at all — are recorded but not yet broken out in the UI.
- No task history browser; the Today summary covers the current day.
- No import, export, or sync — the database is local and yours to back up.
