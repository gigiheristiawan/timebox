TimeBox

A working model of the rotation timebox loop. The timer is timestamp-based, the state machine is explicit, and expiry always stops at a decision — nothing advances on its own.

Menu bar is the primary surface

Title shows ◉ 24:17 while running, ◉ PAUSED when held, ⚠ TIME'S UP at a checkpoint. Click it for the popover — a full day's use never needs the main window.

The rotation strip

Each queued task is a segment sized by its allocation; the current one fills as it burns. The day reads as a playlist, not a to-do list.

Checkpoint has no exit

Five actions, no exits. No dismiss, close, later, or continue — and no timeout that resolves it. Press 1–5, or Return for the recommended choice. A break ends at its own checkpoint rather than dropping you back into work unannounced.

Switching is a decision too

Click any queued task (or ↑/↓ + Return) to jump to it mid-block. The running block is set down, not thrown away — it keeps its remaining time, the task rotates to the back, and returning resumes the remainder. Today counts how often you did it.

Breaks are blocks too

Break is a modifier on the task decision, not a substitute for it. Complete or Keep Pending, each with or without a break — four single-click compound actions. Pick the length first; break time never counts as worked.

Block done ≠ task done

Keeping a task pending completes its time block and rotates the task to the back of the queue. Only an explicit Complete marks the task itself finished.
